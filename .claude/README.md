# Personal Manager Project - Claude Code 中文配置

## 项目特定配置

本项目已配置 Claude Code 使用中文作为主要交互语言，配置包括：

### 语言设置
- **主要语言**: 中文 (chinese)
- **代码交互**: 中文优先
- **文档生成**: 中文格式

### 功能配置
- **详细输出**: 启用详细模式，显示完整的工具输出
- **任务管理**: 启用待办事项功能面板
- **代码风格**: 遵循项目现有的代码规范和命名约定

## 使用指南

### 1. 代码开发
当使用 Claude Code 进行代码开发时：
- 变量和函数名建议仍使用英文
- 注释和文档将自动生成中文
- 错误提示和说明将使用中文显示

### 2. 任务管理
- 使用 `/todo` 命令管理项目任务
- 任务描述将使用中文格式
- 支持中文搜索和过滤

### 3. 代码审查
- 代码审查意见将以中文形式提供
- 改进建议将包含详细的中文说明
- 最佳实践指南将使用中文描述

## 配置覆盖

本项目配置会继承全局中文配置，并添加项目特定的设置：

1. **继承的全局配置** (来自 `~/.claude/settings.json`):
   - 基础语言设置
   - 环境变量配置
   - 权限设置

2. **项目特定配置** (来自 `.claude/settings.json`):
   - 详细输出模式
   - 任务管理功能
   - 项目相关的代码风格指南

## 故障排除

### 问题：中文配置未生效
**解决方案**:
1. 确认 `.claude/settings.json` 文件存在且格式正确
2. 检查全局配置 `~/.claude/settings.json` 是否正确
3. 重启 Claude Code 会话

### 问题：代码建议不符合项目规范
**解决方案**:
1. 在提示中明确说明项目代码规范
2. 使用 `@workspace` 引用项目现有的代码风格
3. 提供具体的项目约定作为参考
